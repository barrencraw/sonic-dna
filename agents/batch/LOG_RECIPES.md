# DNA Batch Parsing - Telemetry Analysis

To analyze the structured logs generated by the DNA batch parsing chain, use the following grep recipe:

```bash
grep "JSON_LOG:" | sed 's/JSON_LOG: //' | jq .
```

### Common Queries

**Filter by Correlation ID:**
```bash
grep "JSON_LOG:" | grep "<correlation_id>" | sed 's/JSON_LOG: //' | jq .
```

**Summarize outcomes for a batch:**
```bash
grep "JSON_LOG:" | grep "<correlation_id>" | sed 's/JSON_LOG: //' | jq -s 'group_by(.outcome) | map({outcome: .[0].outcome, count: length})'
```

**Find all parse errors:**
```bash
grep "JSON_LOG:" | grep '"step": "item_parse"' | grep '"outcome": "error"' | sed 's/JSON_LOG: //' | jq .
```
